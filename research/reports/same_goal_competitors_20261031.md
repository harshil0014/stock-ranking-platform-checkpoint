# Additional competitors matched to the product goal

31October2026. This supplements the56-source review. These candidates are **reviewed, not added to the running tournament**. The laptop remains on its serial low-load queue. Existing sequence results are now exposed; any additional experiments need a separate preregistered follow-up family and cannot be presented as original untouched-holdout evidence.

The product combines two different tasks: rank individual Indian stocks, and help an investor reach a target through recurring contributions. Many papers solve only one. A portfolio allocator cannot fairly be compared using stock-pair accuracy; a next-day stock ranker does not automatically solve12-month SIP goal achievement.

| Candidate | What is already built or published | Match to our goal | Appropriate comparison and remaining work |
|---|---|---|---|
| Temporal Relational Stock Ranking / RSR | Authors' public TensorFlow implementation and paper, tested on NASDAQ/NYSE | Direct stock-selection competitor: ranks expected return using temporal and relational information; no investor-specific SIP goal | Strong follow-up ranking comparator. Adapt relation inputs and labels to India; preserve an identical stock/date cohort. Inspect current licence and legacy runtime before reuse. |
| StockMixer | Official AAAI2024 PyTorch implementation; indicator, temporal and cross-stock MLP mixing | Stock forecasting/selection competitor, with a simpler architecture than many graph/attention systems; no original personalised SIP objective | Useful lightweight follow-up to MASTER/HIST. Use the same OHLCV cohort and matched tabular controls. The original code lists older Python/PyTorch versions; redistribution licence not verified in this pass. |
| MathWorks multiperiod goal-based wealth management RL | Vendor provides an executable example with explicit terminal-goal probability objective | Very close objective match: maximise P(terminal wealth reaches target), but chooses portfolio allocations instead of ranking every stock | A goal-attainment portfolio benchmark on identical contribution schedules, horizon, permissible assets and costs. Requires licensed MATLAB toolboxes; do not describe it as an open-source Python model. |
| G-Learner / GIRL | Dixon and Halperin's published goal-based wealth-management algorithms, including recurring contributions and rebalancing | Strong conceptual SIP match. G-Learner uses an explicitly specified reward; its quadratic formulation is not automatically identical to our binary CAGR target | Review as a goal-aware allocation baseline. A verified turnkey author implementation and usable licence have not been established here. GIRL infers preferences rather than directly improving stock-order accuracy. |
| Goals-based MetaRL(2026) | Das et al., journal paper and detailed methods, annual multi-goal portfolio/goal decisions | Personalised financial goals and allocation; maximises attained-goal utility across years rather than ranking NSE/BSE stocks | Relevant newer goal-planning reference. Author code and pretrained weights were not verified as publicly downloadable. Its reported closeness to dynamic programming is not stock-prediction accuracy or a result on Indian SIPs. |
| FinRL portfolio allocation | Established financial-RL framework, author repository and allocation tutorial | Ready framework for portfolio policies, not a single goal-conditioned stock-ranking champion | A possible implementation platform after defining an Indian recurring-contribution environment and fixed goal/risk reward. Standard A2C/PPO trading returns are not directly our goal objective. Additional environment changes must be called adaptations. |

## Priority

For the stock-ranking product, RSR and StockMixer are the most direct additions to the existing suite. For the personalised investment-goal objective, a goal-probability allocation baseline and a dynamic-programming reference are more informative than adding another generic price predictor. FinRL can implement that environment; it does not itself supply the missing objective or unbiased Indian data.

The next study should separately compare(1)stock ordering and(2)portfolio goal attainment. Keep deposits, horizon, target, initial wealth, assets, costs and information availability identical. Report shortfall and drawdown alongside attainment: a strategy can increase occasional target hits by taking excessive risk. Preserve the current champion and use development-only choices, a new familywise noise calculation, and prospective evidence.

Code availability is distinguished from licence clearance, pretrained weights, reproducible original results and applicability to India. No extra heavyweight training, package installation or cloud spend was started for this review.

## Primary sources

1. Feng et al. Temporal Relational Ranking for Stock Prediction. [Paper](https://arxiv.org/abs/1809.09441), [author implementation](https://github.com/fulifeng/Temporal_Relational_Stock_Ranking). The paper itself links the original repository and describes the US stock dataset and ranking formulation.
2. StockMixer: A Simple Yet Strong MLP-Based Architecture for Stock Price Forecasting. AAAI2024. [Publisher PDF](https://ojs.aaai.org/index.php/AAAI/article/download/28681/29322), [official implementation](https://github.com/SJTU-DMTai/StockMixer). The legacy SJTU-Quant repository redirects to this author organisation.
3. MathWorks. [Multiperiod Goal-Based Wealth Management Using Reinforcement Learning](https://www.mathworks.com/help/finance/multi-period-goal-based-wealth-management-using-reinforcement-learning.html). Vendor code example; the page identifies its required toolboxes and objective.
4. Dixon, M., and Halperin, I.(2020). [G-Learner and GIRL: Goal Based Wealth Management with Reinforcement Learning](https://arxiv.org/abs/2002.10990). [Methods](https://arxiv.org/html/2002.10990v1).
5. Das, S.R., Khadilkar, H., Mittal, S., Ostrov, D., Srivastav, D., and Wang, H.(2026). [A Meta Reinforcement Learning Approach to Goals-Based Wealth Management](https://arxiv.org/abs/2605.02300). Journal of Finance and Data Science12,100186. [Methods](https://arxiv.org/html/2605.02300v1).
6. AI4Finance Foundation. [FinRL author repository](https://github.com/AI4Finance-Foundation/FinRL), [portfolio allocation tutorial](https://finrl.readthedocs.io/en/latest/tutorial/Introduction/PortfolioAllocation.html), [original framework paper](https://arxiv.org/abs/2011.09607).
