# Professor workbook stock-code recovery audit

The user requested computer use. I inspected the available Windows applications; Excel has no open workbook window, and the open Edge windows do not contain the professor sheet. I therefore used the preserved workbook unmatched-code export and archived official NSE/BSE security masters from September 2026. The original workbook is currently absent from its previously recorded path.

The workbook audit has 1,033 unmatched source rows, representing 1,032 unique exchange codes. Exact code joins to the archived exchange masters found 1,027 codes. Of those, 1,025 map to one ISIN and two to multiple ISINs; five remain absent. One uniquely resolved ISIN is already in the 4,436-stock champion under another code. The remaining 1,024 ISINs are absent from the champion, all distinct. These are identity candidates, not automatically eligible rankable equities.

Of the 1,024 new ISIN candidates, 232 occur in the earlier dated security master. Current price, volume, action, history and sector requirements have not been verified for the remaining candidates. No champion scores were invented and the website universe remains 4,436.

Outputs: `experiments/professor-current-fallback-20261003/unmatched_official_master_candidates.csv` contains all 1,032 codes and join multiplicity; `resolved_missing_universe_candidates.csv` contains the 1,025 uniquely joined codes, with current-champion membership.
